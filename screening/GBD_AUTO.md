# GBD 마스터 DB 대규모 자동 평가 — 3,424개사

`python -m screening.gbd_pipeline --xlsx` → `output/screening/gbd_auto_eval.xlsx` (4개 시트).

디캠프 GBD 스타트업 데이터베이스(Ver.26.01, 전체 3,424개사)의 **정형 필드**만으로
500/HAX 엔진의 1차 필터(트랙 라우팅 + 하드 게이트)를 결정적 규칙으로 전 기업에
자동 적용했다. 개별 크롤링·LLM 호출 없음. 대표 이메일·연락처(PII)는 제외.

## 자동화한 것 / 못 한 것
- 자동화 O: 트랙 라우팅(업종·기술·1줄소개 키워드) + 하드 게이트(투자 스테이지).
- 자동화 X: 4축 레벨 점수(v2/v3) — 1줄 소개만으로 신뢰성 있게 못 매긴다.
  점수는 팩트시트를 수집한 102개사(engine_full_eval.xlsx)에서만 산출.
