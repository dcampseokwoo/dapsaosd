## v6에서 바뀐 것
1. **500·HAX 별개 엔진 분리** — 축·스테이지·섹터 정책이 다른 두 프로그램을 config로
   분리(engine_programs.PROGRAMS), 출력도 500 시트 / HAX 시트로 물리 분리.
2. **애매하면 양쪽 평가** — 라우팅 접전은 사람에게 미루지 않고 양쪽 엔진 평가:
   한쪽만 통과=자동확정 / 둘다통과=양 프로그램 후보 / 둘다탈락=확정탈락.
   → '라우팅 사람 확인' 미결 버킷 0.
3. **크로스 리퍼럴** — HAX 스테이지·섹터 탈락이 500 후보면 재활용(61개사).
4. **유사 합격사 매칭(모듈4 신규)** — 점수화·후보 기업에 실제 500/HAX 합격사 35개사
   풀에서 트랙·스테이지·섹터 유사 사례 제시(판단 보조).

## v6.1 개선 (검토/탈락 명확화 + 타겟 시장 + 메일 대비)
- **액션 그룹 정렬**: 각 엔진 시트가 🟢검토 대상 → 🟡경계 → ⚪자료요청 → 🔴확정 탈락
  순으로 정렬 + 상단에 액션별 개수 요약. "검토할 기업 / 탈락할 기업"이 한눈에.
  - 500 엔진: 검토 691 / 경계 213 / 자료요청 141 / 탈락 245
  - HAX 엔진: 검토 344 / 경계 0 / 자료요청 108 / 탈락 127
- **타겟 시장 컬럼**: DB 타겟 국가 필드 → 미국(🇺🇸)/일본/동남아/미상. 미국 프로그램
  (실리콘밸리·뉴어크)이므로 미국 타깃이 Fit↑. 단 DB에 53개사만 기입(미국 21·일본 25)
  → 나머지는 '미상(설문)' = 설문에서 확인할 항목.
- **메일 유형 컬럼(다음 단계 대비)**: 판정 → 발송할 메일 매핑.
  검토 대상 → 내부 검토/지원 안내 · 조건부·자료요청 → 설문 요청 · 확정 탈락 →
  자가진단·보완 안내(탈락 통보 아님).
