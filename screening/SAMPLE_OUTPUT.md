# 엔진 실제 출력 샘플 (2개사)

프롬프트가 요구하는 **버전1 내부용 / 버전2 자가진단용** 두 벌 출력을 실제로 생성한 것.
숫자·Tier 는 `screening/rules.py` 가 계산했고, 사실→레벨 분류 근거는 `screening/dataset.py` 에 있다.
입력은 공개 정보뿐이므로 두 건 모두 **간이 진단 — 설문/증빙 제출 시 정밀 진단 가능**.

## 버전 1: 내부용 (d·camp)

**1. 요약 1줄**
시드 초기 / 500 트랙 / **Tier C (보완 후 재도전)** / Quality 중간 × Fit 높음 — *실제로는 합격한 기업*

**2. 하드 게이트 결과표**

| 게이트 | 판정 | 근거 |
|---|---|---|
| 테크 기업 + 동작 프로토타입 | 통과 | 오프라인 게임 실물 출시·테스트 확인 |
| 풀타임 / 리로케이션 | **조건부** | 설문 미제출 — 창업자 풀타임 여부, SF 상주 의사 확인 필요 |

| C레벨 영어 | **조건부** | 덱/CV 미제출 — 인터뷰에서 확인 |

**3. 신뢰성 스캔** — 전체 `정상`

| 항목 | 판정 | 비고 |
|---|---|---|
| 교차 문서 수치 일관성 | 정상 | 비교할 제출 문서 없음 (판정 근거 부족) |
| 산술/환율 오류 | 정상 | 상동 |
| 고객 vs 위시리스트 | 정상 | 유료 고객 주장 자체가 없음 |
| 자기인용 | 정상 | — |
| 과장 표현 | 정상 | — |

**4. 축별 레벨 + 근거 + 증거 등급**

| 축 | 레벨 | 근거 사실 | 증거 등급 |
|---|---|---|---|
| Traction (40) | **L2** | 출시·유료화 증거 공개 없음. 오프라인 검증 단계 = 금전적 증거 없는 파일럿 | 확인 필요 |
| Team (30) | **L4** | 대표 손수현 — 넥슨·크래프톤(PUBG) 게임 기획/제작. 스케일업·엑싯 이력은 미확인 | 문서 명시(보도) |
| Market (20) | **L3** | 글로벌 TCG/보드게임 시장 대형이나 상향식 $1B 논증 없음 | 추정 |
| Moat (10) | **L3** | AI 제작 파이프라인 + 오프라인→온라인 검증 루프. 구축 증거 없음 | 문서 명시(보도) |

가중평균 **2.90** → Tier **C** (강등 규칙 미적용)

**5. `확인 필요` 리스트** — MRR·유료 전환 지표 / 풀타임 여부 / SF 리로케이션 의사 / 캡테이블

**6. 유사 합격 사례 + 경쟁사 누락**
- ⚠️ **Step 6.5 정상 수행 실패**. 500 포트폴리오 페이지가 JS 렌더링 + 접근 차단이라
  섹터·스테이지로 필터링된 합격 사례를 특정하지 못했다. 확인된 것은 프로그램 레벨 정보뿐:
  500 Global 상위 투자 섹터는 Financial Services / Software / SaaS / FinTech / AI 이며,
  게임 스튜디오는 대표 섹터에 없다. 다만 500·Creators HQ 의 Creators Ventures
  액셀러레이터(지원 1,100건 → 21팀 선발)처럼 크리에이터·콘텐츠 인접 트랙은 존재한다.
- 경쟁사 누락 플래그: **판정 불가** (지원사 경쟁사 슬라이드 미제출)

**7. 추천 전 확인사항 체크리스트**
- [ ] 오프라인 게임의 실제 판매량·재구매율 (금전적 증거로 Traction L2 → L4 상향 가능)
- [ ] AI 제작 파이프라인이 내부 툴인지 판매 가능한 플랫폼인지
- [ ] 500 Global 이 이미 프리시드 투자자 — 후속 배치 참여의 실질 목적 확인
- [ ] 창업자 3인 이상 풀타임 여부, SF 4개월 상주 가능 여부

**8. `판정 불안정` 플래그**
- Team L4 ↔ L3: 앵커 9개사 중 3개만 제공되어 페어와이즈 비교 불가 → **L3 로 내리면 Tier 는 C 유지(2.60)**

## 버전 2: 자가진단용 (스타트업)

### 🟡 보완 후 지원

**보완 과제 (우선순위순)**
1. **금전적 증거를 만드십시오.** 지금 지원서에서 가장 약한 곳은 트랙션입니다. 오프라인 게임의
   누적 판매 부수, 재구매율, 객단가 — 숫자 3개면 충분합니다. 없으면 심사는 "아직 안 팔아봤다"로 읽습니다.
2. **온라인 전환 1개를 실제로 마치십시오.** "오프라인 검증 후 온라인 전환" 전략은 전환 사례가
   0건이면 가설입니다. 1건이 있으면 전략이 됩니다.
3. **AI 제작 플랫폼의 정체를 정하십시오.** 내부 생산성 도구인지, 외부에 파는 제품인지에 따라
   시장 규모 논거가 완전히 달라집니다.
4. **월별 성장률로 말하십시오.** 500 은 누적치가 아니라 MoM 속도를 봅니다. 최근 3~6개월 월별 수치를 준비하세요.
5. 풀타임 여부·SF 4개월 상주 가능 여부를 지원서에 명시하십시오. (미기재 시 자동 `조건부`)

**예상 인터뷰 질문 5개**
1. 오프라인에서 검증했다는 건 구체적으로 몇 개 타이틀, 몇 부, 어떤 채널입니까?
2. 넥슨·크래프톤 경력이 '작은 팀으로 빠르게 출시하는' 능력으로 어떻게 이어집니까?
3. AI 제작 파이프라인으로 타이틀 1개 만드는 데 드는 시간과 비용이 그전 대비 얼마나 줄었습니까?
4. 카드/보드게임 시장에서 당신들의 유통 채널은 무엇이며, 그게 왜 방어 가능합니까?
5. 4개월 뒤 데모데이에서 보여줄 단 하나의 지표는 무엇입니까?

**유사 합격 사례** — ⚠️ 이번 진단에서는 섹터가 일치하는 합격 사례를 특정하지 못했습니다
(500 포트폴리오 데이터 접근 실패). 500 의 공개된 주력 섹터는 SaaS·핀테크·AI 이며,
게임 스튜디오는 주력에 없습니다 — 이는 Quality 가 아니라 **Fit** 논거를 따로 준비해야 한다는 뜻입니다.

**신뢰성 스캔에서 발견된 수치 오류** — 없음 (검증할 수치가 제출되지 않았습니다)

프리시드 / HAX 트랙 / **Tier C (강등 규칙으로 B→C)** / Quality 높음 × Fit 높음 — *실제로는 합격, 이후 시드 $18.7M*

**2. 하드 게이트 결과표**

## 버전 2: 자가진단용 (스타트업)

### 🟡 보완 후 지원

**보완 과제 (우선순위순)**
1. **고객 신호를 하나라도 만드십시오.** 이 진단에서 등급을 끌어내린 유일한 요인은 고객 축입니다.

3. 파일럿 → 실증(500톤) 사이의 스케일업 리스크를 스스로 먼저 열거하십시오.

**예상 인터뷰 질문 5개**
1. 상온·상압 공정이 파일럿에서 실증 규모로 갈 때 가장 먼저 깨지는 가정은 무엇입니까?
2. 바나듐 순환 손실률은 얼마이고, 그것이 원가 모델에 어떻게 반영됩니까?
3. 광석 품위가 달라지면 회수율은 어떻게 변합니까?
4. 첫 상업 고객은 광산사입니까 제련사입니까, 그리고 그들의 구매 결정권자는 누구입니까?
5. 기존 제련소를 대체하는 게 아니라 보완한다면, 그 사업 모델은 무엇입니까?

**유사 합격 사례** — HAX 동문 Neptune Robotics(수중 로봇), XFuel(해양 연료), YPlasma(플라즈마).
공통점은 *물리적 산업의 원가 구조를 바꾸는 하드웨어* 입니다. 귀사는 이 테마에 정면으로 부합합니다.

- "최대 90% 저비용" — 비교 기준(어떤 규모의 어떤 제련 공정 대비인지)이 함께 제시되지 않으면
  심사에서 과장으로 읽힙니다. 기준선을 명시하십시오.
