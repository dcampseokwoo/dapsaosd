## 1-A. 대원칙

> **배제는 비가역이고 하향은 가역이다. 확실할 때만 배제한다.**

메일 발송 비용이 0이므로, 애매한 것을 배제해 잃는 것이 애매한 것을 T2에 두어 잃는 것보다 크다.
단 **T1은 엄격하게** — 최우선 명단의 신뢰도가 리스트 전체의 신뢰도다.

## 1-B. 질문 4개

| | 질문 | 선택지 |
|---|---|---|
| **Q1** | 이 제품이 **최종적으로 기여하는 것**은 무엇인가?<br>※ "누구에게 파는가"가 **아니다** | 산업 생산 / 의료 치료·진단 / 연구 / 국방·공공 / 개인의 미용·생활·취미·의복 / 혼합 / 불명 |
| **Q2** | 자기 설계로 만드는가, 남의 설계를 받아 만드는가? | 자체설계 / 수탁(OEM·ODM) / 유통·중개 / 불명 |
| **Q3** | 파는 것이 무엇인가? | 물건 / 소프트웨어·서비스 / 콘텐츠·IP / 혼합 |
| **Q4** | 규제 범주는? | 해당없음 / 의료기기 / 의약품 / 화장품 / 식품 / 방산 / 복수 |

**Q1이 이 규칙의 핵심이다.** "누구에게 파는가"로 해석하면 B2B 부품·소재 회사가 전부 "산업체"가 되어 소비재 부품사가 통과한다. 실측 사례: 제일저지(의류 브랜드에 원단 납품), 크레신(오디오 브랜드에 ODM 납품).

## 1-D. 규칙 9의 판별 기준 (가장 논쟁적인 지점)

규칙 9a와 9b를 가르는 것은 **"소재·부품·공정을 자체 개발하는가"** 하나다. 실측 사례로 기준을 고정한다.

| 기업 | 소재 자체개발 | 근거 | 판정 |
|---|---|---|---|
| 에코디엠랩 | **있음** | "압전세라믹**부터** 완제품까지 자체 생산" | 9a → T2 |
| 제일저지 | **있음** | "기능성 니트 원단의 **원사 개발**·편직·가공·봉제 일괄 생산" | 9a → T2 |
| 아람휴비스 | **없음** | "AI 영상 진단기 + 화장품 추천 시스템" — 소재·부품 언급 없음 | 9b → 배제 |
| 에잇컵스 | **없음** | "smart tumblers that help users manage their weight" | 9b → 배제 |
| 리얼디자인테크 | **없음** | "cycling equipment for home training" | 9b → 배제 |

**판별 신호:** 원료·소재·부품·공정 단계를 명시적으로 언급하는가. "~부터", "일괄", "수직계열화", "원사 개발", "원료 생산" 등.
**주의:** 조립·설계만으로는 해당하지 않는다. AI·소프트웨어 자체 개발도 해당하지 않는다.

## 1-E. 확정된 개별 판단

| 기업 | 판정 | 근거 |
|---|---|---|
| 에코디엠랩 | T2 + `own_material_consumer_end` | 압전세라믹 자체 생산 |
| 제일저지 | T2 + `own_material_consumer_end` | 원사부터 개발. 에코디엠랩과 동일 구조이므로 동일 판정 |
| 아람휴비스 | **배제** | 소재 자체개발 근거 없음 |
| 울트라브이 | T2 + `mixed_regulatory` | 의료기기 + 기능성 화장품 |
| 마린테크노 | T2 + `mixed_regulatory` | 화장품 + 아미노산 비료 |
| 대명화학 | T2 (T1 금지) + `established_suspect` | 도메인 충돌. 대형 계열사 |
| 벤텍스 | T2 + `mixed_end_use` | 용도가 넓음 |
| **포레** | **보류 → Phase 3까지 T3** | 가정용/업소용 판별 불가. 홈페이지 보강 대상 |

## 현재 엔진(v6)과의 차이 메모 (Phase 6 반영 시 확인)

- 현재 엔진 tier는 `verdict × 플래그(consumer_facing/maturity)` 기반. v3는 **Q1~Q4 + 결정표**
  기반이라 판정 로직 자체가 다르다 → Phase 6에서 규칙 엔진으로 교체.
- v3 규칙 5(화장품 단독=배제)는 현재 v5/v6의 consumer 배제와 대체로 일치하나, 규칙 6
  (복수 규제=T2 mixed_regulatory)·규칙 9a(소재 자체개발 소비재=T2)는 현재 T1/T2 경계와
  다르게 동작할 수 있다(예: 현재 T1인 케이스가 v3에선 T2로 내려갈 수 있음).
- 규칙 0·1(정보부족·도메인충돌 → 홈페이지 보강/T1 금지)은 현재 엔진에 없는 신규 개념.
  Phase 3(홈페이지 수집) 이후라야 규칙 0이 온전히 동작한다.
- `대명화학`은 이번 라운드에서 consumer(배제)로 처리했는데, v3는 `T2 + established_suspect`
  (도메인 충돌)로 규정 → Phase 6에서 재조정 대상.
